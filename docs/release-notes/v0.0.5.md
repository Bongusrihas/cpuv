# cpuv 0.0.5

This source release adds pinned Git, archive, local source and SDK declarations, native build adapters, verified compiler and tool provisioning, and offline development transfers. Read the [development guide](../phase2.md) and [compatibility gate](../phase3.md) for supported workflows.

- Run `cpuv sync` to regenerate metadata in projects with an older sealed dependency environment. Installed environments now bind the exact provider lock and saved toolchain state.
- Cache repair preserves damaged package, tool, archive, index and deployed snapshot objects in quarantine. Official MSYS2 archive retries can use the mirror service and still verify the indexed size and SHA-256.
- CPUV installs libraries whose linker metadata requires an explicit choice. Select the modules a consumer actually uses in `[link].pkg_config`, or select imported targets in its native build. Inspect `.cpuv/env/link-plan.json` for the resulting compiler arguments.
- MSYS2 compiler compatibility checks use the package build base from the index. Dependency resolution and linker selection use upstream metadata and explicit project declarations.
- Online MSYS2 installs use the verified archive and CAS cache for recovery. Offline sync and development export can produce an independent environment snapshot.
- Source copies track deleted inputs, MSBuild tests receive runtime variables, and bundles retain assets and empty directories. Cache maintenance reports protected storage and previews recognized log cleanup.

See the [maintenance review](../maintenance-review.md) for migration details and the [project matrix](../project-matrix.md) for live repository, installation and consumer evidence.
